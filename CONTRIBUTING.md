# Contributing to ImGuiQuic

Thanks for helping improve ImGuiQuic. Bug reports, focused fixes, documentation,
and compatibility improvements are welcome.

## Before you start

- Search existing issues and pull requests before opening a duplicate.
- Use an issue for substantial design changes so the approach can be discussed.
- Keep pull requests focused on one feature or fix.
- Never include build output, downloaded dependencies, virtual environments, or
  local configuration.

## Local setup

Install Git, CMake 3.21+, a C++17 compiler, Clang with C++20 support, ICU development files, Node.js 22+, and Python 3.10+ for
binding regeneration (`dear_bindings` requires 3.10+). Then build from the
repository root:

```bash
cmake -B build -DIMGUI_QUIC_BUILD_EXAMPLES=ON -DIMGUI_QUIC_BUILD_TESTS=ON
cmake --build build
```

The first CMake configure fetches the pinned Dear ImGui source into an ignored
local directory. Frontend files are served separately; changes require a page reload.
For browser verification, prepare development certificates and use
`build/examples/imgui_quic_dev` as described in the [native transport guide](tools/webtransport/README.md).
The browser requires its configured WebTransport launch URL.

## Required checks

```bash
cmake -B build -DIMGUI_QUIC_BUILD_EXAMPLES=ON -DIMGUI_QUIC_BUILD_TESTS=ON
cmake --build build
ctest --test-dir build --output-on-failure
node tests/browser/draw_ip.mjs
node tests/browser/webtransport.mjs
node tests/browser/clipboard_shortcuts.mjs
node tests/browser/large_clipboard_batch.mjs
node tests/browser/media_viewer.mjs
node --check frontend/imgui_quic_draw.js
node --check frontend/imgui_quic.js
python3 -m py_compile tools/dear_bindings/generate.py
git diff --check
```

Use clear commit messages and explain user-visible behavior, testing, and any
compatibility impact in the pull request.

## Generated bindings

The native C API and metadata are generated by `dear_bindings`:

- `include/imgui_quic_imgui.h`
- `src/imgui_quic_imgui.cpp`
- `tools/dear_bindings/imgui_quic_imgui.json`

Keep `imgui_quic.h` lifecycle-only. Do not handwrite broad ImGui wrappers.

Regenerate with:

```bash
python3 tools/dear_bindings/generate.py
```

This command fetches the pinned Dear ImGui and `dear_bindings` revisions into a
temporary directory. Include metadata and all generated output in the same
change so reviewers can reproduce it.

## Reporting security issues

Do not open a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md)
instead.

## Install via CMake or vcpkg

```bash
cmake --install build --prefix /path/to/install
```

Consumers use `find_package(imgui_quic CONFIG REQUIRED)` and link
`imgui_quic::core`. Frontend assets install under `share/imgui_quic/frontend`;
serve that directory independently. Ship the private QUICHE library and its notices.

The development overlay port builds this checkout:

```bash
IMGUI_QUIC_LOCAL_SOURCE_DIR="$PWD" vcpkg install imgui-quic --overlay-ports="$PWD/ports"
```

A published registry and release archive hash will be added when a release is
cut. The port supports Linux x64/arm64 and bundles the pinned Dear ImGui revision.
